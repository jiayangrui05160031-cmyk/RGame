# rgame

<p align="right"><strong>中文</strong> | <a href="README_EN.md">English</a></p>

俯视角单屏肉鸽游戏。Windows / Android / iOS 跨平台，自动攻击，三武器循环，五关战役 + 无尽模式。

战斗视觉采用深海军蓝与青色能量核心的太空风格；主角、十三种敌人与虚空守卫共享象牙白装甲、蓝钢结构和克制的紫色强调。v4 增加主菜单火星战役插画、四款主角皮肤、九款武器图标、新版拾取物和战斗特效。

## 项目说明

这是把 rgame 游戏设计方案落地到一个**工程化 Python 项目**的实现：

- **核心库**：所有规则、状态机、伤害、敌人、抽卡、掉落、成就、存档、日志——`rgame/`。**完全无 GUI 依赖**，可单独用 pytest 测试。
- **渲染层 A · pygame 桌面**：`rgame/render/pygame_app.py`（默认）。Windows / macOS / Linux 直接跑。
- **渲染层 B · Kivy 跨平台**：`rgame/render/kivy_app.py`。Android / iOS 横屏，触屏 + 虚拟摇杆。Windows 上也可作 Kivy 桌面版。
- **构建/发布**：Kivy 端口到 Android 用 buildozer（需要 Linux/macOS 主机）；iOS 用 kivy-ios（需要 macOS 主机）。视觉与音频规范见 [VISUAL_AUDIO_REQUIREMENTS.md](VISUAL_AUDIO_REQUIREMENTS.md)。

## 安装与运行

```bash
# 安装依赖
pip install pygame "kivy[base]" pytest

# 启动 pygame 桌面端（默认）
python main.py --seed 42

# 启动 Kivy 跨平台（移动端推荐）
python main.py --backend kivy --platform android

# 仅自检引擎（无 GUI）
python main.py --headless

# 跑测试套件
python -m pytest -q
```

## 玩法

1. 主菜单 → 模式选择（五关战役 / 无尽）→ 预设选择（三形态）
2. WASD/方向键移动，或点击地面自动移动；Q 或点击右下武器卡切换，鼠标右键停止移动，Esc 暂停
3. 自动攻击最近目标；近战会挥剑并显示扇形范围，远程弹体锁定发射方向后不会追踪
4. 击杀得分达到抽卡门槛后进入三选一；除伤害、生存、机动和武器升级外，可搭配暴击与离子散射构筑，金色可能获得激光炮等高阶武器
5. 怪物会持续刷新，击杀可掉落经验、治疗和护甲；达到关底分数后停止刷新，清完场上怪物或击杀 Boss 才能换关
6. 第四关会触发矿脉共振，第五关会遭遇轨道锁定；预警圈可躲避，完成后奖励金币和一次抽卡
7. 无尽模式以 5000 分 / 循环推进，循环死亡结算
8. 每关 Boss 最迟在关卡开始 25 秒出现；虚空守卫会使用七种攻击模式，包括棱镜炮列和带旋转安全缺口的虚空潮汐，阶段提升后弹幕加快、核心节点加速旋转
9. 第三关起逐步加入游击、相位突袭、修复支援和棱镜炮兵；优先处理治疗支援，并沿 Boss 弹幕的安全缺口移动

## 测试矩阵

`tests/` 下的自动化测试会按四层逐步扩充：

- **规则层**：伤害公式、武器循环、卡牌叠加、抽卡费用、敌人强化、命中检查、上限约束。
- **集成层**：击杀 → 分数 → 抽卡 → 成就 / 拾取 → 升级。
- **场景层**：完成五关、连续多级、暂停、超级怪兽警告、重开。
- **平台层**：键鼠 / 触屏、屏幕边界、对象池。

当前仓库已接入基础启动、配置契约和资源校验测试；测试数量以本地 `python -m pytest -q` 的实际结果为准，后续每增加一类玩法就同步增加对应测试，不再在文档中预先声称尚未存在的测试数量。

资源校验可单独运行：

```bash
python rgame/tools/verify_assets.py
```

## 已知边界

- Kivy 移动端打包（Android / iOS）当前在测试机上以 pygame 桌面版替代；Kivy 端口结构已留接口。
- pygame 与 Kivy 共用 v3/v4 玩家、敌人和战斗特效立绘，以及 v5 战术拾取物图标；pygame 提供可切换主角皮肤、武器图标、主菜单插画和近战斩击效果，Kivy 同步显示新皮肤、武器图标、拾取物与命中特效。
- 远程敌人的预警会锁定射击点；战术电容可缩短主动技能冷却，临时加速和超频拾取物会实际生效。v5 图标的裁切顺序与提示词见 `rgame/assets/v5/ASSET_PROMPTS.md`。
- 持续优化中的新内容（矿脉寄生体、轨道炮台、磁轨长弓、熔核无人机及第 4/5 关背景）目前只存在于本地开发分支，用户验收通过后再推送远程仓库。
